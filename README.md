# TFont

**Status:** research bootstrap / proof-of-concept planning.

TFont is an experimental semantic interoperability layer for Text-Fabric / Context-Fabric corpora. The project maps corpus-native node types, features, edge relations, and controlled values to shared open semantic standards while preserving the native corpus as the scholarly authority.

Initial interoperability targets:

- ETCBC BHSA
- DT-UCPH CUC
- ETCBC Syriac corpora (including `syriac`, `peshitta`, and `syrnt` as applicable)
- ETCBC `extrabiblical`
- TLHdig-TF

The first project phase is **research only**. Architecture, ontology governance, agent/human ergonomics, and documentation/distribution contracts must be established before implementation tickets are accepted.

See `AGENTS.md` for the automated development loop and the GitHub issue tracker for the research backlog.
